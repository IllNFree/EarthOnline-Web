## 三、模块二：智能堆叠与动态网格系统

| 能力 | 实现要点 |
|---|---|
| 底层网格 | `GRID = 10`，坐标与尺寸一律经 `snap()` 取 10 的倍数 |
| 拖拽磁吸 | `computeGuides()`：与邻近节点左/中/右、上/中/下对齐且偏差 < 7 画布坐标时吸附，并显示琥珀色虚线辅助线（SVG 层） |
| 碰撞避让 | `resolveCollisions()`：被覆盖节点沿**最小重叠轴**推开，最多 5 轮收敛；固定节点不动、面板节点不参与 |
| 一键整理 | `autoLayout()`：面板按 `CANVAS_PANELS` 序号三列铺顶，其余节点按堆叠偏好铺成卡片墙；动画期间开启弹簧过渡 |

实测：整理后 6 块面板构成规整 3 列 × 2 行网格，同行 top 完全一致，**节点互相重叠对数 = 0**。

|---|---|

## 五、模块四：全局实体关联引擎

### 5.1 底层统一
- **唯一事实来源 = `biLinks` 一张表**。画布连线由 `ops.rebuildRelationEdges(state)` 从该表派生，两端永远同源。
- **无向对语义**：`setEntityRelations()` 用 `pairKey`（两端 ID 排序后拼接）配对 —— 同一对实体只保留一条记录，**任一端解除，两端同步消除**。
- **详情页关联 → 画布长线**：`rebuildRelationEdges` 内 `ensure()` 为尚未上画布的实体自动补节点（先经 `entityExists()` 校验实体真实存在，避免为已删实体造空节点），落位在已有节点右侧空白处避免重叠。
- **画布连线 → 详情页关联记录**：同一张表派生，详情页无需额外同步逻辑。
- **反向索引**：详情页底部「被引用」区自动展示哪些实体指向了我。
- **内联链接并表**：`ops.syncInlineBiLinks()` 把笔记正文的 `@[Type:ID]` 同步进同一张表（带 `inline` 标记），正文移除引用即自动解除。
- **级联软删防死链**：软删实体时连带软删其关联记录与画布节点，并重建连线，不留孤边。

### 5.2 通用关联组件（不重复造轮子）
| 组件 | 职责 |
|---|---|
| `src/components/EntitySearchDialog.vue` | 全应用**唯一**的关联弹窗：8 个类型 Tab + 全局搜索 + 多选勾选 |
| `src/components/EntityRelationsPanel.vue` | 关联展示面板：出向「我关联的」+ 入向「被引用」，点击跳转 |

已接入详情页：**任务 / 背包 / 相册 / 足迹 / 记账 / 笔记**（共 6 处），全部使用同一对组件与同一底层表。

## 六、模块五：设置页单页锚点定位

- **废除多级导航**：删除左侧二级导航（`.set-nav`），改为顶部 sticky 水平锚点条 + 单页垂直流。
- **单页垂直流**：7 个分区（个人资料 / 外观 / 画布设置 / 通知 / 桌面级交互 / 数据·备份 / 关于）全部常驻渲染，`<section id="sec-*">` 依次排列，区块间以虚线分隔。
- **锚点导航**：点击顶部标签平滑滚动至对应区块；滚动时按元素位置差自动高亮当前标签；滚到底部强制高亮末项。
- **实现要点**：滚动容器是外层 `.page`（`overflow-y:auto`），`mainRef` 挂在 `.page` 上；定位用 `root.scrollTop + (target.rect.top - root.rect.top) - 12`（`offsetTop` 受 `offsetParent` 影响不可靠）。

## 八、修复的真实 Bug

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 打开新建面板后整个画布失去响应 | `CanvasCreateSheet` 无 ESC 关闭，其全屏遮罩（z-index 120）挡住所有交互 | 增加 `keydown` 监听，`Escape` → `emit('close')` |
| 2 | 「一键整理」在只有数据面板时毫无反应 | `autoLayout()` 把 `type !== 'panel'` 的节点全过滤掉了 | 面板改为按 `CANVAS_PANELS` 序号三列铺在顶部，参与整理 |
| 3 | 左侧悬浮工具栏压住第一列面板 | 面板网格原点 x=40，未给工具栏留位 | 新增 `PANEL_ORIGIN_X = 110`；`fitToContent()` 左侧预留 84px。实测遮挡节点数 = 0 |
| 4 | 已删除实体仍会被拉入画布生成空节点 | `rebuildRelationEdges` 只查节点不查实体 | 增加 `entityExists()` 校验（`ledger` 为 `{records:[]}` 对象容器，需单独处理） |
| 5 | 设置页锚点点击无反应 | 滚动容器是 `.page` 而非 `.set-main`，且用了不可靠的 `offsetTop` | `mainRef` 改挂 `.page`，定位改用 rect 差值计算 |
| 6 | **关联弹窗完全打不开** | `EntitySearchProvider` 把 `state.ledger` 当数组 → `(state.ledger || []).filter is not a function` 抛错，computed 渲染中断。记账在 state 里是对象容器 `{records:[], expenseCategories:[], incomeCategories:[]}` | 新增 `ledgerRecords(state)` helper，兼容数组与对象两种形态 |
| 7 | 4 个详情页关联面板类型失效 | `<EntityRelationsPanel :type="task" />` 漏了引号，Vue 当成 JS 变量（undefined） | 静态属性改写 `type="task"`（Tasks / Album / Ledger / Map 四处） |
| 8 | 关联弹窗触发 Vue prop 警告 | `sourceType/sourceId` 声明 `required: true`，父组件初始传 `null` | 改为 `default: ''` |
