## 四、逐条实现方案

1. **主页视图切换**：`HomeView` 动态组件 + `DashboardHome` / `WhiteboardHome`，默认视图存 `homeDefaultView`（设置中心可配）。
2. **全实体节点化 + 自定义样式**：`EntityNode` 按 `type` 渲染不同卡片；拖拽边缘调大小（`w/h` 持久化）；右键菜单改背景色（`color` 持久化）。
3. **泛实体语义连线 + 双向跳转**：`CanvasNavigator.navigate()` —— 画布有节点则平滑聚焦闪烁；否则 Haze 确认框「是否创建」；拒绝则降级路由。节点内 `@[Type:ID]` 标签可点击触发。
4. **外部文件拖入孵化**：`FileNodeFactory` 识别 image/audio/video/pdf → 相册 / 收藏 + 画布媒体节点（音频带播放控件）。
5. **剪贴板多态孵化**：`ClipboardNodeFactory` 按 MIME 分派（image→相册 / URL→收藏 / 纯文本→笔记）+ 画布节点；`useClipboardWatcher` 在页面可见时读取并弹 Haze 气泡。
6. **桌面级生产力交互**：右键菜单（开关真生效）、全局拖拽上传、剪贴板监听，均为全局组件。
7. **系统通知**：`useNotificationService`。
8. **静态导出**：`useHtmlExport.exportCanvas()` 序列化画布为只读 HTML（Haze 静态降级）。
9. **自定义看板**：`CustomDashboard` 用 `grid-layout-plus`，模块经 `REGISTRY` 注册，布局持久化 + 同步。
10. **AI 报告**：`ReportRenderer` 渲染复盘 / 总结为洞察节点。
11. **跨端融合**：`useWebDAVSync` 根级挂载；`ToolExecutor` 创建实体后自动落节点；`BiLinks` 与画布关联合并；导入后生成节点群；`design-tokens` 统一动画。
12. **实体检索与定位**：`CanvasEntitySearch` 全局检索 → 定位节点 / 在此创建。

## 风险清单
- **画布性能**：DOM 节点在百级规模流畅；千级需虚拟滚动（当前未做，标注为后续优化）。
- **剪贴板权限**：`navigator.clipboard.read()` 需页面聚焦授权；拒绝时静默降级（已处理）。
- **View Transitions 浏览器差异**：`usePageTransition` 不支持时降级 CSS（已处理）。
- **Haze 低端掉帧**：`backdrop-filter` 保留满血；导出副本做静态降级（已处理）。
- **Leafer 替换点**：若后续接入 `@leafer-free/board`，需将其 HTML-overlay 与现有 Haze 节点渲染对齐，并回归 Puppeteer QA。

## 红线核对
- Haze 满血：所有画布/气泡/菜单/看板均走 `backdrop-filter`，仅导出静态副本降级。 ✅
- 契约：新节点 / 连线 / 反向索引全纳入 `webdav.js mergeBackup` + `sanitizeState`。 ✅
- 全局复用：右键 / 拖拽 / 剪贴板 / 通知 / 导出 / 画布桥均为全局。 ✅

- 双向链接：覆盖 task/memo/item/photo/collection/location/ledger 全实体。 ✅
