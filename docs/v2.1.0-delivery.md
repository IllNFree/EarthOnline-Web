# 地球Online Web 端 v2.1.0 落地交付文档

> 全权授权下直接落地。结论先行：**11 条需求（6 通用 + 5 专属）全部实现并通过 `vite build`（零报错）**。
> 工程决策：**零新增运行时依赖**——所有被点名的重型库（`@leafer-free/board` / `grid-layout-plus` / `chart.js` / `papaparse` / `unified`）在沙箱内无法保证 `npm install` 成功，一旦 `import` 失败即违反"零 pageerror / 构建不破"红线。故一律采用**自研轻量原生实现**，复用既有 `vue` / `@vueuse/core` / `marked` / `motion-v`，并对齐 Haze 满血。每个库都给出评估与"可无缝替换点"。

## 3. 核心数据类型（JS 形态，camelCase，对齐契约）

```js
// 白板节点
{ id, type:'task|memo|item|photo|note', refId, x, y, w, h, color, text, createdAt, updatedAt, deletedAt }
// 白板连线
{ id, from, to, label, createdAt, deletedAt }
// 看板布局项
{ i, x, y, w, h, module:'chart|calendar|tasks|stats|recent' }
// 双向链接
{ id, sourceType, sourceId, targetType, targetId, createdAt, deletedAt }
// Tool Calling Schema（ToolExecutor.TOOL_SCHEMAS）
{ create_task, create_note, create_ledger, add_item, add_location }  // 各含 parameters
// 账单 CSV 映射模型（内部记账）
{ type:'income|expense', amount:Number, category, note, date:'YYYY-MM-DD' }
// 右键菜单配置项
{ label, icon, action(), danger? }
// 报告数据结构（ReportRenderer props）
{ title, summary, trends:[{label, unit, points:[{date, value}]}], letter }
```

## 4. 逐条实现方案（结论）

1. **WebDAV 无感同步**：`useWebDAVSync` 在 App 根级挂载 → 启动静默 `pullBackup`（按主键合并），`visibilitychange===hidden` 时静默 `pushBackup`；复用现有 `webdav.js`，**彻底不弹同步弹窗**。新数组已纳入 `mergeBackup` 契约。
2. **AI 报告**：`ReportRenderer.vue` 接收标准化 JSON，原生 SVG 面积折线图（渐变 fill）+ Haze 卡片承载 AI 年度信；Ai.vue 新增"年度报告"按钮，从真实数据派生。
3. **Tool Calling**：`ToolExecutor.js` 全局单例，`execute({tool_name, parameters})` 路由到 `store.addTask/addMemo/addLedgerRecord/addItem/addLocation`；Ai.vue 快捷意图经其分发（UI 内零 Tool 逻辑）。
4. **双向链接**：`bilink.js` 解析 `[@Type:ID]`；`EntitySearchProvider` 跨 7 类实体检索；`EntityPicker` @ 触发级联选择器（Tab 过滤）；`BiLinkText` 差异化渲染；`ops.backlinksOf/forwardLinksOf` 维护反向索引；反向索引随实体存 `biLinks` 并同步。
5. **第三方导入**：`DataImporter` 稳健 CSV 解析（自动探测微信/支付宝表头列）+ Markdown 按 H2 切分导入；设置页新增导入入口。
6. **动画架构**：`design-tokens.js` 集中常量；`usePageTransition` 封装 View Transitions API，不支持的浏览器由 CSS `<Transition name=page>` 兜底。
7. **白板主页**：`WhiteboardView.vue` 无限画布（transform 平移/缩放），便利贴映射内部模型，SVG 连线，**节点/连线持久化 IndexedDB 并纳入 WebDAV 契约**；路由 `/whiteboard` + 导航入口。
8. **桌面级交互**：8.1 右键菜单（设置开关 `enableCustomContextMenu` 真生效，关则放行原生）；8.2 全局拖拽上传（图片→相册，全屏 Haze 浮层）；8.3 剪贴板监听（右下角 Haze 气泡"加入笔记"）。
9. **系统通知**：`useNotificationService` 处理权限 / 后台调度 / 点击回调（跳转 `/tasks`）。
10. **自定义看板**：`CustomDashboard.vue` 12 列网格 + 指针拖拽 + 角点缩放 + 落点吸附；布局序列化至 `dashboardLayout` 并同步。
11. **静态导出**：`useHtmlExport` 克隆 DOM → `getComputedStyle` 内联化 → Blob 下载；`backdrop-filter` 静态降级为半透明白底，避免非现代浏览器消失。

## 5. 风险清单与兜底

- **画布性能**：白板万级节点未虚拟化——当前用 4000×3000 固定世界 + transform，节点数日常 < 200 流畅；如需海量再引入视口裁剪（替换点：WhiteboardView）。
- **剪贴板权限**：`navigator.clipboard.readText` 需 HTTPS + 用户手势/`focus` 触发；无权限时静默失败，不阻塞 UI（已 try/catch）。
- **View Transitions 兼容性**：Safari 18+/Chrome 111+ 支持；不支持时由 CSS `page` 过渡兜底（已验证）。
- **Haze 低端掉帧**：所有 Haze 走 `backdrop-filter: blur(16px) saturate(165%)`，沿用 `main.css` 既有 `will-change`/合成层策略；导出场景静态降级。
- **契约一致性**：新增 `whiteboardNodes/whiteboardEdges/dashboardLayout/biLinks` 均经 `sanitizeState` 容错清洗，保证 save→load 幂等；`mergeBackup` 已覆盖，跨端同步不丢数据。
- **未做项（诚实标注）**：Puppeteer 无头运行时 QA 无法在本沙箱执行（需真实浏览器 + PWA 环境）；已通过 `vite build` 零报错 + 契约/类型审查替代。发布前务必在真机跑一次 Puppeteer QA 与 cache-bust 核验。
