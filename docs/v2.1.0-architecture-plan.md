# 地球Online · Web v2.1.0 高阶需求架构方案

> 规划文档，非实现。覆盖 11 条需求（6 通用 + 5 Web 专属），全部逐条对照。
> 现状锚点（已存在，严禁重复造轮子）：
> - `src/lib/webdav.js` —— 现有 WebDAV 同步契约（camelCase / 主键合并 / 软删对齐），需求 1 必须在其上增强。
> - `src/stores/app.js` —— 全局设置（透明度/开关），需求 8.1 开关落此处。
> - `src/lib/ai.js` —— AI 调用与解析，需求 2/3 复用。
> - `src/lib/search.js` —— 跨实体检索，需求 4 复用为 `EntitySearchProvider` 底座。
> - `src/lib/model.js` —— `defaultState` / `APP_INFO`（版本号同步处）。
> - `src/lib/ops.js` —— Task / Note / Ledger / Backpack 操作服务，需求 3 路由目标。
> - `src/lib/storage.js` —— IndexedDB（localForage）封装，新增 store 统一走此处。
> - 缺 `src/composables/`、`src/services/`、`src/components/` 部分 —— 本方案新建。

## 3. 核心接口与数据类型（TypeScript）

```typescript
// ===== 7. 白板节点 / 连线 =====
type WbNodeKind = 'sticky' | 'note' | 'task' | 'photo';
interface WhiteboardNode {
  id: string;            // 主键（camelCase）
  kind: WbNodeKind;
  x: number; y: number;  // 画布坐标
  w: number; h: number;
  text?: string;         // sticky 文本
  refType?: 'note' | 'task' | 'photo'; // 关联内部实体
  refId?: string;        // 指向 notes/tasks/photos 主键
  z: number;
  createdAt: string; updatedAt: string;
  deletedAt: string | null; // 软删对齐
}
interface WhiteboardEdge {
  id: string;
  fromId: string; toId: string; // 指向 WhiteboardNode.id
  label?: string;
  createdAt: string; deletedAt: string | null;
}

// ===== 4. Bi-Links 全局关联索引 =====
type EntityType = 'note' | 'task' | 'backpack' | 'photo' | 'ledger' | 'footprint';
interface EntityRef { type: EntityType; id: string; }
interface BiLinkIndex {
  id: string;                       // 主键
  fromType: EntityType; fromId: string;
  toType: EntityType;   toId: string;
  createdAt: string; deletedAt: string | null; // 反向索引同样软删
}
// 渲染层解析语法： @[note:abc123]  @[task:xyz]
interface ParsedBiLink { type: EntityType; id: string; raw: string; }

// ===== 3. Tool Calling Schema =====
interface ToolCall {
  tool_name: 'create_task' | 'create_note' | 'add_ledger' | 'add_backpack';
  arguments: Record<string, unknown>; // 严格遵循中台 JSON Schema
  call_id?: string;
}
interface ToolResult { ok: boolean; tool_name: string; data?: unknown; error?: string; }

// ===== 5. CSV 映射模型 =====
interface CsvTransaction {            // 微信/支付宝账单 → 内部记账
  id: string;                        // 主键（导入时生成，避免冲突）
  type: 'income' | 'expense';
  amount: number;
  category: string;
  counterparty: string;              // 商户/对方
  note: string;
  occurredAt: string;                // ISO
  source: 'wechat' | 'alipay' | 'other';
  deletedAt: string | null;
}
interface ImportResult { inserted: number; skipped: number; errors: string[]; }

// ===== 8.1 右键菜单配置项 =====
interface ContextMenuItem {
  id: string; label: string; icon?: string; // 矢量 SVG，禁 Emoji
  action?: () => void; disabled?: boolean;
  children?: ContextMenuItem[];
}
interface ContextMenuConfig {
  zone: string;                       // 区域标识（列表/白板/看板…）
  items: ContextMenuItem[];
}
```

## 4. 逐条实现方案

### 需求 1 · WebDAV 无感自动同步
- **技术要点**：复用 `src/lib/webdav.js` 现有契约（`camelCase` / 主键合并 / 软删）。启动：`App.vue` `onMounted` 调 `useWebDAVSync().pull()` 静默拉取，全程不弹窗（现有同步弹窗彻底移除）。推送：`document.addEventListener('visibilitychange', () => { if (document.hidden) sync.push() })`。冲突策略沿用现有「主键合并 + updatedAt 较新胜出」。
- **关键签名**：`useWebDAVSync(): { pull(): Promise<void>; push(): Promise<void>; status: Ref<'idle'|'sync'|'error'> }`
- **注意**：拉取失败静默重试（指数退避，最多 3 次），不阻塞 UI；隐藏推送仅在 `hidden` 时，避免前台频繁写。

### 需求 2 · AI 主动服务与报告
- **技术要点**：`ReportRenderer.vue` 接收中台下发的标准化 JSON（`{ trends: TrendPoint[]; annualLetter: string }`）。图表用 `chart.js` 封装，视觉对齐 Android Vico（统一配色/圆角/网格）；Haze 满血（`backdrop-filter: blur(16px) saturate(165%)` + 高光边 + `::before/::after`），年度报告页全屏 Haze 容器。
- **关键签名**：`ReportRenderer(props: { report: StandardReport })`
- **注意**：图表数据量大时按视口懒渲染；Haze 容器隔离独立层，防 `backdrop-filter` 在父级 `overflow:hidden` 失效。

### 需求 3 · Tool Calling 意图分发
- **技术要点**：`ToolExecutor.js` 单例，消费中台 JSON Schema。路由表 `Map<tool_name, (args)=>Promise<ToolResult>>` → 分别调 `ops.js` 的 Task/Note/Ledger/Backpack 写服务。所有参数经 camelCase 归一 + 必填校验（可选 `zod`）。
- **关键签名**：`ToolExecutor.execute(call: ToolCall): Promise<ToolResult>`
- **注意**：结果回写 AI 会话；执行失败不抛 UI，落库为草稿并 Toast。

### 需求 4 · 双向链接（系统级）
- **技术要点**：数据层新增 IndexedDB store `bilinks`（结构见 §3），正向 `@[Type:ID]` 与反向索引同表维护（删实体时级联软删关联）。编辑层 `GlobalBiLinkEditor` 监听 `@` 触发 `EntitySearchProvider.query(type, keyword)`（底座复用 `search.js`，可选 `fuse.js` 模糊）。渲染层 `BiLinkParser.parse(text)` → 按 Type 渲染不同 Chip（任务带勾选框 / 背包物品卡 / 笔记引用块）。
- **关键签名**：`EntitySearchProvider.query(type: EntityType|'all', kw: string): Promise<EntityRef[]>`；`BiLinkParser.parse(src: string): ParsedBiLink[]`；`bilink.js upsertLink(from, to)` / `reverseOf(type,id): Promise<BiLinkIndex[]>`
- **注意**：**必须覆盖 note/task/backpack/photo/ledger/footprint 全部核心实体**，严禁只针对某一类硬编码；反向索引查询走索引避免全表扫。

### 需求 5 · 第三方数据导入
- **技术要点**：`DataImporter` 用 `papaparse` 解析 CSV（自动识别微信/支付宝列头映射），转 `CsvTransaction[]`（camelCase、主键生成防冲突、软删默认 null）；Markdown 用 `unified`+`remark` 动态 `import()` 转内部笔记结构。映射严格对齐中台 Schema。
- **关键签名**：`DataImporter.importCsv(file: File): Promise<ImportResult>`；`DataImporter.importMarkdown(file: File): Promise<ImportResult>`
- **注意**：大文件分片解析防主线程卡顿；导入前预览映射结果，用户确认再写库。

### 需求 6 · 全局动画架构统一
- **技术要点**：`design-tokens.js` 导出 `DURATION/EASING/DELAY` 常量；`usePageTransition()` 在 router 钩子里包 `document.startViewTransition()`，不支持（`!document.startViewTransition`）降级 Vue `<Transition>`。
- **关键签名**：`usePageTransition(): { navigate(to: RouteLocationRaw): void }`
- **注意**：严禁页面内硬编码动画参数；降级路径保证 Safari <18 / Firefox 也有过渡。

### 需求 7 · 画布式白板主页
- **技术要点**：`@leafer-free/board` 提供 `EditorCanvas`/`RenderCanvas`；便利贴节点映射 `WhiteboardNode`（可关联 note/task/photo 通过 `refType/refId`）；连线存 `WhiteboardEdge`，二者新 store 纳入 WebDAV 同步契约（camelCase/软删）。与列表视图通过顶部切换器互斥显示。
- **关键签名**：`WhiteboardView(props: { mode: 'list'|'board' })`
- **注意**：装 `@leafer-free/board` 前复核 License 与维护；大量便利贴 + 连线启用视口裁剪/分层，避免重绘掉帧。

### 需求 8 · 桌面级生产力交互（三项全做）
- **8.1 右键菜单**：`useContextMenu()` 首行读 `app.js` 设置 `enableCustomContextMenu`；`false` 时 `return`（不 `preventDefault`，放行原生）。`GlobalContextMenu.vue` 液态玻璃 + 边界检测 + ESC/空白关闭 + 多区域 `zone` 差异化。
- **8.2 拖拽上传**：`useGlobalDropZone()` 监听 window `dragover`(preventDefault)/`drop`，`GlobalDragOverlay.vue` 全屏 Haze 浮层，落文件调 `DataImporter`/附件写库。
- **8.3 剪贴板监听**：`useClipboardWatcher()` 在 `visibilitychange→visible` 时 `navigator.clipboard.readText()`（需先前用户聚焦过页面），非空则 `HazeToast` 右下角气泡「是否加入笔记」。
- **关键签名**：`useContextMenu(zone: string): { open(x,y,config): void }`；`useGlobalDropZone(): { isDragging: Ref<boolean> }`；`useClipboardWatcher(): { lastText: Ref<string|null> }`
- **注意**：**开关必须真生效**（读设置 + 早退）；剪贴板读取需用户手势历史，Safari 限制严格，失败时静默不报错。

### 需求 9 · 系统级桌面通知
- **技术要点**：`NotificationService` 单例：首次用 `Notification.requestPermission()`；`visibilitychange→hidden` 启动定时扫描到期任务（或 SW 推送）；点击 `notification.onclick` → `focus()` + 路由到对应任务页。
- **关键签名**：`NotificationService.scheduleCheck(); NotificationService.requestPermission(): Promise<NotificationPermission>`
- **注意**：权限被拒后 UI 内引导，不反复弹；SW 推送复用现有 PWA service worker。

### 需求 10 · 终极自定义看板
- **技术要点**：`grid-layout-plus@^1`，`<GridLayout>`+`<GridItem>` 包裹图表/日历模块；布局数组序列化存 IndexedDB（新 store 或 settings 键），纳入 WebDAV 同步；模块通过注册制（`registerWidget(name, comp)`）接入，禁硬编码。
- **关键签名**：`CustomDashboard(props: { widgets: WidgetRegistration[] })`
- **注意**：用 `^1` 稳定版，避开 v2 beta 破坏性变更；响应式断点 `breakpoints` 配置。

### 需求 11 · 静态网页一键导出
- **技术要点**：`useHtmlExport()` 克隆目标 DOM → 遍历 `getComputedStyle` 内联样式 → 拼完整 HTML → `new Blob([html],{type:'text/html'})` → 临时 URL 下载。Haze 降级：导出时把 `backdrop-filter` 替换为静态半透明背景 + 边框，避免非现代浏览器完全消失。
- **关键签名**：`useHtmlExport(): { exportDom(el: HTMLElement, meta: {title:string}): Blob }`
- **注意**：内联样式体积可能大，导出前剥离无用节点；图片转 base64 或保留远程 URL（只读场景）。

## 5. 风险清单

| 风险 | 影响 | 兜底 |
|------|------|------|
| 画布性能（Leafer 大量便利贴 + 连线重绘） | 低端机掉帧、白板卡顿 | 视口裁剪、分层渲染、`content-visibility`、节点超阈值降级为缩略 |
| 剪贴板权限兼容性 | Safari/Firefox 限制 `readText`，需用户手势历史 | 读取失败静默；提供手动「粘贴到笔记」入口 |
| View Transitions 浏览器差异 | Safari<18 / Firefox 不支持 | `usePageTransition` 自动降级 CSS `<Transition>`，体验不中断 |
| Haze 在低端设备掉帧 | 多层 `backdrop-filter` 叠加 GPU 压力 | 隔离 Haze 层、限 `will-change`、满血不砍模糊但控制同时存在的 Haze 实例数 |
| WebDAV 三方库不成熟 | `@rcarls/idb-free-sync` 0.x 单一维护者 | **不引入**，复用现有 `webdav.js` 自封装，契约零风险 |
| PWA 离线包体积膨胀 | chart.js/unified/grid-layout 进 bundle | 动态 `import()` 按需加载；cache-bust 核验；首屏体积预算监控 |
| 契约破坏 | 白板/看板/连线/反向索引漏 camelCase 或漏软删 | 新 store 统一走 `storage.js`，迁移脚本含软删列；契约断言 CI 校验 |
| 右键开关假生效 | 用户关了仍拦截原生菜单 | `useContextMenu` 早退 + 单测覆盖开关两种状态 |
| 双向链接只覆盖部分实体 | 违背红线 7 | `EntitySearchProvider` 枚举全实体类型，新增实体必须登记 |
